                             AllBinary Platform XD Pascal

What is it?

This repository contains code generated by the AllBinary Platform for support in XD Pascal.  
This repo is used to allow developers to skip the XD Pascal code generation step.

What are some example games with this XD Pascal code?

https://allbinary.itch.io (The downloads with "-xdpascal" in the filename are XD Pascal only builds. Currently that only includes nothing. Also the XD Pascal builds are not available on Google Play or other stores.)
